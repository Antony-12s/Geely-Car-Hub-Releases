# Geely Car Hub releases

Public APK downloads and SHA-256 checksums only. Application source is maintained privately.

Download the latest APK and SHA256SUMS.txt from [Releases](https://github.com/Antony-12s/Geely-Car-Hub-Releases/releases/latest). Verify the checksum before sideloading. The in-app update button uses this repository without GitHub credentials.

Diagnostic ZIPs are private until you explicitly share/export them. Never upload reports, passwords, signing keys or personal data to this repository. Review report contents before sending them to a trusted developer.

Updates use Android confirmation and do not silently disable EX5 installation-verifier settings. Firmware restrictions may require separately authorized installation help. See each release note for tested scope and known limits.
